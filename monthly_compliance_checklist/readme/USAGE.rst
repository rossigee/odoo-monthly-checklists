Usage
=====

Daily Operations
----------------

**Viewing Monthly Checklists:**

1. Navigate to **Accounting → Compliance → Monthly Checklists**
2. The current month's checklist is created automatically
3. Click on a checklist to view all compliance items
4. Monitor the completion percentage in the list view

**Managing Check Items:**

Each checklist contains multiple check instances that track specific requirements:

* **Green checkmark**: Item is completed
* **Orange dot**: Item is pending
* **Progress bar**: Shows overall checklist completion

**Completing Manual Items:**

Some checks require manual confirmation:

1. Open the check instance
2. Review the requirements
3. Click "Mark as Complete" when satisfied
4. Add notes if needed

Creating Historical Checklists
------------------------------

To create checklists for past months:

1. Go to **Accounting → Compliance → Backfill Wizard**
2. Select the date range (start and end months)
3. Choose whether to skip existing checklists
4. Click "Create Checklists"

Working with Templates
----------------------

**Creating a New Template:**

1. **Accounting → Compliance → Check Templates**
2. Click "Create"
3. Fill in the basic information:
   
   * Name and sequence
   * Check type
   * Validity period (optional)
   * Auto-create monthly option

4. Configure type-specific settings based on your selection
5. Save the template

**Template Types and Settings:**

* **Partner Payment Check**: Select partners, set amount thresholds
* **Partner Invoice Check**: Choose invoice types and partners
* **Attachment Check**: Define file requirements and patterns
* **Combined Checks**: Configure both transaction and attachment rules

Monitoring Compliance
---------------------

**Dashboard View:**

The monthly checklist list view provides:

* Period display (YYYY-MM format)
* State indicators (draft, active, completed, cancelled)
* Completion percentage
* Total vs completed items count

**Filtering and Searching:**

Use the search bar to:

* Filter by period (year, month)
* Show only active or completed checklists
* Search by specific check names

**Re-evaluating Checks:**

If transactions change:

1. Open the affected check instance
2. Click "Re-evaluate Condition"
3. The system will recheck all criteria
4. Status updates automatically

Best Practices
--------------

1. **Regular Review**: Check the monthly checklist weekly to ensure timely completion
2. **Template Maintenance**: Review templates quarterly to ensure they match current requirements
3. **Historical Accuracy**: Use the backfill wizard carefully to maintain data integrity
4. **Documentation**: Use the notes field to document any exceptions or special circumstances
